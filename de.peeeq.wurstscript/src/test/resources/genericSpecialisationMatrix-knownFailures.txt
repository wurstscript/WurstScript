# Cases of GenericSpecialisationMatrixTests (the pull-request tier) which fail on master, each with the
# defect class its symptom belongs to. Jass passes every one of them: these are Lua defects.
#
# A case listed here is reported as skipped with its failure; a failure not listed fails the test, and a
# listed case which passes is named in the summary for removal. The run writes the list it would leave in
# test-output/generic-matrix/knownFailures-after-this-run.txt.
#
#   lua-fixed-static-1498        a store with a fixed type argument (Cell<X>) used inside a generic class is
#                                written and read in different copies behind erased dispatch (#1498)
#   lua-static-erased            a per-instantiation static of a generic class, reached through erased
#                                dispatch, reads an erased copy: shared by the instantiations, or never
#                                initialised (nil)
#   lua-instanceof-erased        `x instanceof Box<int>` is true for a Box<string>, Box<CB> for Box<CA>
#   lua-bound-unresolved         Lua rejects a type-class requirement reached through a non-generic interface,
#                                base class, super call or destroy ("could not be resolved for the Lua target")
#   lua-closure-receiver         Lua rejects a closure in a bounded or constructing generic class which reads
#                                a field ("Could not adapt receiver G_specialized_X to superclass G")
#   lua-new-instance-unresolved  Lua rejects wurstNewInstance<T>() in a constructor, an ondestroy or behind a
#                                super call ("requires its type argument to resolve to a concrete class")
#   lua-new-instance-dangling    Lua translation crashes when wurstNewInstance<T>() is reached through a
#                                non-generic interface or base class ("dangling reference ... wurstNewMarker")
#   lua-new-instance-wrong       the instance wurstNewInstance<T>() made is not the one read back (reads 0)
#   lua-field-split              a T-typed instance field written through one copy of the class is read
#                                through another (nil or default)
#   lua-storage-nil              a subclass of a generic class instantiated with a tuple reads a nil
#                                *_storage global
#   lua-tuple-subclass-crash     ConcurrentModificationException in Lua translation: a subclass of a generic
#                                class instantiated with a tuple, called through a generic interface
#   lua-tuple-elimination-crash  EliminateTuples throws ("//// Before") on a tuple static written in a
#                                closure of a generic class
